# Spec Delta

## Purpose

دستیار سند، دستیار هوش تجاری و نمایش ساختاریافته‌ی نتیجه.

## ADDED Requirements

### Requirement: Document assistant
دستیار سند SHALL در فهرست Agentها باشد. پاسخش SHALL به سند و بخش مربوط ارجاع دهد و کاربر منبع را باز کند. اگر جوابی در اسناد مجاز نباشد SHALL همین را بگوید و جواب نسازد.

#### Scenario: Answer with citation
- **WHEN** کاربر درباره‌ی مرخصی می‌پرسد
- **THEN** پاسخ با نام سند و بخش دیده می‌شود و منبع قابل باز کردن است

#### Scenario: No answer
- **WHEN** پرسش به اسناد مجاز ربطی ندارد
- **THEN** دستیار می‌گوید پاسخی پیدا نکرد

### Requirement: Data assistant results
دستیار هوش تجاری SHALL نتیجه را جدول، نمودار (میله‌ای، خطی، دایره‌ای) یا کارت عددی نشان دهد، نوع نمایش را بر پایه‌ی شکل داده پیشنهاد دهد، به کاربر اجازه‌ی تغییر نوع بدهد، کوئری اجراشده را نشان دهد و دانلود CSV و Excel بدهد.

#### Scenario: Switch display
- **WHEN** کاربر از «میله‌ای» به «جدول» می‌رود
- **THEN** همان داده در جدول دیده می‌شود

#### Scenario: Show query
- **WHEN** کاربر «نمایش کوئری اجراشده» را می‌زند
- **THEN** کوئری فقط‌خواندنی دیده می‌شود

#### Scenario: Write request
- **WHEN** کاربر می‌خواهد داده‌ای حذف شود
- **THEN** دستیار می‌گوید انبار داده فقط‌خواندنی است

#### Scenario: Unknown metric
- **WHEN** داده‌ای پیدا نمی‌شود
- **THEN** پیام ساده می‌گوید چه چیزی پیدا نشد و چه کنید

### Requirement: Automatic assistant routing
اگر کاربر Agent انتخاب نکرده، مسیریاب SHALL برای پرسش داده‌ای یا سندی در صورت دسترسی، دستیار مناسب را خودکار بگذارد و دلیل را زیر پاسخ بنویسد.

#### Scenario: Auto data assistant
- **WHEN** کاربر بدون انتخاب Agent درباره‌ی فروش می‌پرسد
- **THEN** پاسخ ساختاریافته می‌آید و «مسیریاب ... دستیار هوش تجاری» دیده می‌شود
