# Spec Delta

## Purpose

ثبت واقعی ارائه‌دهنده‌ی مدل و گرفتن فهرست مدل‌هایش در پنل ادمین.

## ADDED Requirements

### Requirement: Register a provider with a real key
ثبت ارائه‌دهنده SHALL نام، نشانی پایه و کلید را بگیرد، ارائه‌دهنده را ذخیره کند و کلید را فقط روی سرور و رمزنگاری‌شده نگه دارد. کلید SHALL بعد از ثبت به هیچ‌کس نمایش داده نشود.

#### Scenario: Register
- **WHEN** ادمین فرم را درست پر و ثبت می‌کند
- **THEN** ارائه‌دهنده در فهرست می‌آید و بعد از تازه‌کردن صفحه هم هست

#### Scenario: Key failure
- **WHEN** ذخیره‌ی کلید شکست می‌خورد
- **THEN** پیام «کلید ذخیره نشد» دیده می‌شود

### Requirement: Fetch the real models list
بعد از ثبت، و با «دریافت دوباره‌ی فهرست»، سامانه SHALL از ارائه‌دهنده فهرست مدل‌ها را بگیرد. مدل‌های تازه غیرفعال وارد می‌شوند. خطا (کلید نپذیرفته، اتصال برقرار نشد) SHALL با پیام روشن نشان داده شود.

#### Scenario: Models received
- **WHEN** ارائه‌دهنده پاسخ می‌دهد
- **THEN** مدل‌ها با وضعیت «غیرفعال» دیده می‌شوند

#### Scenario: Rejected key
- **WHEN** ارائه‌دهنده کلید را نمی‌پذیرد
- **THEN** پیام «کلید پذیرفته نشد» و وضعیت خطا دیده می‌شود

### Requirement: Persist model settings
فعال یا غیرفعال‌کردن مدل، نام نمایشی، توضیح و ویژگی‌ها SHALL ذخیره شود و بعد از تازه‌کردن صفحه بماند.

#### Scenario: Enable
- **WHEN** ادمین مدلی را فعال می‌کند و صفحه را تازه می‌کند
- **THEN** مدل فعال می‌ماند
