# Spec Delta

## Purpose

چت واقعی با مدل‌های فعال‌شده توسط ادمین.

## ADDED Requirements

### Requirement: Models from the admin
فهرست مدل‌های پنل کاربر SHALL مدل‌های فعال ارائه‌دهنده‌های ثبت‌شده باشد. اگر هیچ مدل فعالی نیست، فهرست نمونه می‌ماند.

#### Scenario: Enabled models
- **WHEN** ادمین یک مدل را فعال کرده است
- **THEN** همان مدل در انتخاب مدل چت دیده می‌شود و مدل‌های غیرفعال نه

### Requirement: Real streaming answer
پیام با مدل واقعی SHALL به ارائه‌دهنده فرستاده شود و پاسخ کلمه‌به‌کلمه نمایش داده شود. کاربر SHALL بتواند توقف کند. خطا SHALL با پیام روشن و دکمه‌ی «تلاش دوباره» دیده شود و پیام‌های قبلی سالم بمانند. با مدل واقعی فعلاً ابزار و دستیارهای نمونه اجرا نمی‌شوند و فایل‌های پیوست به مدل داده نمی‌شوند.

#### Scenario: Answer
- **WHEN** کاربر با یک مدل واقعی پیام می‌فرستد
- **THEN** پاسخ مدل به‌تدریج نوشته می‌شود و نام مدل زیرش دیده می‌شود

#### Scenario: Provider error
- **WHEN** ارائه‌دهنده خطا می‌دهد
- **THEN** پیام خطا با «تلاش دوباره» دیده می‌شود
