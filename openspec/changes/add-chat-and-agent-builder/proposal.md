# Proposal

## Why

موشکاف دو پنل دارد: پنل ادمین (ساخته شده، در پوشه‌ی جدا) و پنل کاربر که جایی است که کارمندان سازمان واقعاً از هوش مصنوعی استفاده می‌کنند. الان پنل کاربر وجود ندارد. این تغییر اولین نسخه‌ی آن را با «سند نیازمندی‌های دستیار سازمانی» (بخش‌های چت، انتخاب مدل، اتصال‌ها، فراخوانی Agent و ساخت Agent) هم‌خوان می‌کند تا کاربر عادی بتواند گفتگو کند، مدل و اتصال و Agent انتخاب کند و Agent شخصی خودش را بسازد. پنل کاربر یک برنامه‌ی جدا روی پورت جدا (۳۰۰۱) است و ظاهر و رفتارش مثل پنل ادمین است (فارسی، راست‌به‌چپ، همان فونت و رنگ‌ها، تم روشن و تیره).

## What Changes

دو صفحه‌ی اصلی ساخته می‌شود: **صفحه‌ی چت** و **صفحه‌ی ساخت و ویرایش Agent**.

- **قاب پنل کاربر**: ورود (ساختگی)، منوی کناری با «گفتگو» و «Agentهای من»، تم روشن/تیره، موبایل‌پسند.
- **چت** (CHAT-01 تا 09): فهرست گفتگوها با جست‌وجو، گفتگوی تازه، تغییر نام و حذف از فهرست خود کاربر؛ ارسال پیام و پاسخ مرحله‌به‌مرحله با دکمه‌ی توقف؛ پیوست PDF و Word و Excel و تصویر با نمایش وضعیت پردازش و خطا و برداشتن پیوست پیش از ارسال؛ پیوست فقط در همان گفتگو؛ زیر هر پاسخ نام مدل، ابزارهای به‌کار‌رفته و منبع‌ها؛ پیام خطای روشن؛ نمایش مصرف و سهمیه‌ی باقی‌مانده و جلوگیری از ارسال وقتی سهمیه تمام شده؛ هشدار داده‌ی حساس پیش از ارسال.
- **انتخاب مدل** (MDL-01 تا 06): فهرست قابل جست‌وجوی مدل‌های فعال و مجاز با نام، توضیح کوتاه و قابلیت‌ها، گزینه‌ی «انتخاب خودکار»، مدل انتخاب‌شده کنار کادر پیام، مدل واقعی کنار پاسخ، پیشنهاد مدل سازگار (پیشنهادی) و قانون مدل داخلی در Agent حساس.
- **انتخاب اتصال** (INT-01 تا 07): فهرست اتصال‌های مجاز با ابزارها و وضعیت آماده‌بودن، روشن/خاموش‌کردن برای هر گفتگو، نمایش اتصال‌های انتخاب‌شده کنار کادر پیام، پرسیدن تأیید پیش از اجرای ابزار، نمایش وضعیت اجرا و نتیجه در چت، بررسی دوباره‌ی دسترسی پیش از هر اجرا.
- **فراخوانی Agent در چت** (AGT-01 تا 08): فهرست Agentهای شخصی و اشتراکی، نمایش مشخصات پیش از انتخاب، انتخاب با دکمه یا تایپ `@`، نمایش نام Agent کنار کادر پیام، خروج از حالت Agent، پیشنهاد گفتگوی جدا، و عدم اجرای Agent غیرفعال یا بدون دسترسی همراه با دلیل.
- **ساخت و ویرایش Agent** (BLD-01 تا 13): فرم نام، هدف، دستورالعمل، مدل پیش‌فرض، اتصال‌ها و ابزارها، مهارت‌ها؛ فقط گزینه‌های مجاز؛ انتخاب ابزار از هر اتصال؛ وارد‌کردن مهارت آماده یا ساخت مهارت شخصی که تا تأیید ادمین غیرفعال است؛ آزمایش Agent در پنل چت؛ اعتبارسنجی؛ فهرست «Agentهای من»؛ استفاده‌ی شخصی بلافاصله پس از ذخیره؛ درخواست اشتراک‌گذاری با وضعیت در انتظار/تأییدشده/ردشده (با دلیل)؛ پرچم «حساس» که فقط ادمین تعیین می‌کند؛ هشدار خروج بدون ذخیره.
- حالت‌های بارگذاری، خالی، بدون دسترسی، در انتظار تأیید و خطا در همه‌ی صفحه‌ها.
- همه‌چیز با داده‌ی آزمایشی محلی است و با تازه‌کردن صفحه به حالت اول برمی‌گردد. هیچ پاسخ واقعی هوش مصنوعی، پیوست واقعی یا اتصال واقعی در کار نیست.

## Capabilities

### New Capabilities

- `user-panel-shell`: قاب پنل کاربر، ورود، منو، مسیرها و قواعد مشترک حالت‌ها (بارگذاری، خالی، بدون دسترسی، در انتظار تأیید، خطا).
- `user-chat`: گفتگوها، ارسال و پاسخ، پیوست‌ها، منبع‌ها، خطاها، مصرف و سهمیه، هشدار داده‌ی حساس.
- `user-model-picker`: انتخاب مدل و قواعد سازگاری و مدل داخلی.
- `user-connections`: انتخاب اتصال‌ها و تأیید و اجرای ابزارها در چت.
- `user-agent-chat`: انتخاب و استفاده از Agent در چت.
- `user-agent-builder`: ساخت، ویرایش، آزمایش و درخواست اشتراک‌گذاری Agent.

### Modified Capabilities

هیچ (پنل کاربر پروژه‌ی تازه است و مشخصه‌ی اصلی ندارد؛ پنل ادمین دست نمی‌خورد).

## Impact

- پوشه‌ی جدید `New-Moshekaf-User-Panel` (کنار پنل ادمین) با اجرای `npm run dev` روی پورت ۳۰۰۱. طراحی، فونت، قطعه‌های `ui` و قطعه‌های مشترک از پنل ادمین کپی شده‌اند.
- مسیرها (برنامه‌ریزی‌شده): `/login`، `/chat`، `/chat/[conversationId]`، `/agents`، `/agents/new`، `/agents/[agentId]`.
- بخش‌های `chat`، `models-catalog`، `connections`، `agents` و `user-session` زیر `src/features` با داده‌ی آزمایشی محلی.
- پنل ادمین و مخزنش بدون تغییر می‌مانند. در فاز ۲ هر دو پنل به یک بک‌اند وصل می‌شوند؛ دسترسی‌ها و قواعد حساس باید آن‌جا سمت سرور اعمال شوند (اینجا فقط در رابط شبیه‌سازی می‌شوند).

## Out of Scope

مدیریت ارائه‌دهنده‌ها، ثبت فنی MCP و API، تأیید درخواست‌ها، تعیین سهمیه، مدیریت اسناد سازمان، گزارش کامل کاربران در پنل ادمین، طراحی گردش‌کار (workflow)، و تنظیم اتصال به پایگاه داده. همچنین: پاسخ واقعی مدل، OCR واقعی، ذخیره‌ی ماندگار هر چیزی، آرتیفکت کنار چت (در این تغییر نیست)، و ثبت‌نام کاربر.

## Decisions

کاربر در تاریخ ۱۴۰۵/۰۷/۲۷ (۲۰۲۶-۱۰-۱۹) همه‌ی گزینه‌های پیشنهادی را تأیید کرد:

1. **عوض‌کردن مدل وسط گفتگو**: از پیام بعدی مدل تازه جواب می‌دهد و پیام‌های قبلی همان مدل قبلی را نشان می‌دهند.
2. **مدل پیش‌فرض Agent**: کاربر هنگام صدا‌زدن Agent نمی‌تواند مدل را عوض کند؛ Agent با مدل پیش‌فرض خودش اجرا می‌شود.
3. **تاریخچه هنگام ورود به Agent**: Agent فقط از همان لحظه می‌بیند و پیشنهاد می‌شود گفتگوی جدا شروع شود.
4. **استثنا در قاعده‌ی تأیید ادمین**: Agent شخصی بلافاصله پس از ذخیره برای خود کاربر فعال است؛ مهارت و اتصال تازه‌اش تا تأیید ادمین غیرفعال می‌ماند.
