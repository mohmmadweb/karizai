# Spec Delta

## Purpose

انتخاب و استفاده از Agent در گفتگو.

## ADDED Requirements

### Requirement: Agent picker
کاربر SHALL بتواند از دکمه‌ای داخل کادر پیام یا با تایپ `@` یک منوی کشویی از نام Agentهای شخصی و اشتراکی را ببیند. هدف، مدل پیش‌فرض و ابزارهای هر Agent در صفحه‌ی «Agentهای من» دیده می‌شود.

#### Scenario: Open with the button
- **WHEN** کاربر دکمه‌ی Agent را می‌زند
- **THEN** فهرست با بخش‌های «شخصی» و «اشتراکی» و جست‌وجو دیده می‌شود

#### Scenario: Open with @
- **WHEN** کاربر در کادر پیام `@` تایپ می‌کند
- **THEN** همان فهرست باز می‌شود و ادامه‌ی تایپ آن را فیلتر می‌کند

#### Scenario: No Agents
- **WHEN** کاربر Agentی ندارد
- **THEN** حالت خالی با پیوند «ساخت Agent» دیده می‌شود

### Requirement: Agent mode
پس از انتخاب، نام Agent SHALL کنار کادر پیام دیده شود و کاربر بتواند با یک کلیک به گفتگوی معمولی برگردد. Agent با دستورالعمل، مدل پیش‌فرض و ابزارهای خودش اجرا می‌شود و دسترسی واقعی‌اش SHALL هرگز بیشتر از دسترسی خود کاربر نباشد (ابزاری که کاربر به آن دسترسی ندارد اجرا نشود).

#### Scenario: Select and leave
- **WHEN** کاربر Agent را انتخاب می‌کند و بعد خارج می‌شود
- **THEN** نام Agent کنار کادر دیده می‌شود و پس از خروج برداشته می‌شود

#### Scenario: Tool beyond user's access
- **WHEN** Agent ابزاری دارد که کاربر به آن دسترسی ندارد
- **THEN** آن ابزار اجرا نمی‌شود و در جزئیات پاسخ دلیلش آمده است

### Requirement: Suggest separate conversation
هنگام شروع Agent در گفتگویی که پیام دارد، پیشنهاد SHALL بیاید که گفتگوی جدا شروع شود؛ کاربر انتخاب می‌کند. (پیشنهادی؛ جزئیات تاریخچه در سؤال‌های باز است)

#### Scenario: Start in a new conversation
- **WHEN** کاربر در گفتگوی دارای پیام Agent انتخاب می‌کند و «گفتگوی جدید» را برمی‌گزیند
- **THEN** گفتگوی تازه با آن Agent باز می‌شود

#### Scenario: Continue here
- **WHEN** کاربر «ادامه در همین گفتگو» را برمی‌گزیند
- **THEN** Agent در همین گفتگو فعال می‌شود

### Requirement: Disabled or revoked Agent
اگر Agent غیرفعال شده یا دسترسی به آن لغو شده، SHALL اجرا نشود و دلیل به‌روشنی دیده شود.

#### Scenario: Disabled Agent
- **WHEN** کاربر Agent غیرفعال را انتخاب می‌کند
- **THEN** اجرا نمی‌شود و پیام «این Agent غیرفعال است» با دلیل دیده می‌شود
