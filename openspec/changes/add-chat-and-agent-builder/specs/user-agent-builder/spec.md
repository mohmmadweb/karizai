# Spec Delta

## Purpose

ساخت، ویرایش، آزمایش و درخواست اشتراک‌گذاری Agent شخصی از صفحه‌ی «Agentهای من».

## ADDED Requirements

### Requirement: My Agents list
صفحه‌ی «Agentهای من» SHALL Agentهای شخصی کاربر را با نام، هدف، مدل پیش‌فرض و وضعیت اشتراک نشان دهد و دکمه‌ی «ساخت Agent» و ویرایش داشته باشد.

#### Scenario: List
- **WHEN** کاربر صفحه را باز می‌کند
- **THEN** Agentهای خودش با وضعیتشان دیده می‌شوند

#### Scenario: Empty
- **WHEN** Agentی ندارد
- **THEN** حالت خالی با دکمه‌ی «ساخت اولین Agent» دیده می‌شود

### Requirement: Agent form
فرم Agent SHALL فیلدهای نام، هدف، دستورالعمل، مدل پیش‌فرض، اتصال‌ها و ابزارها و مهارت‌ها را داشته باشد. نام، دستورالعمل و مدل پیش‌فرض SHALL اجباری باشند. فقط مدل، ابزار و مهارتی که کاربر به آن دسترسی دارد SHALL قابل انتخاب باشد.

#### Scenario: Create
- **WHEN** کاربر فرم را درست پر می‌کند و ذخیره می‌زند
- **THEN** Agent ساخته می‌شود و در «Agentهای من» می‌آید

#### Scenario: Required fields
- **WHEN** نام یا دستورالعمل یا مدل خالی است
- **THEN** ذخیره نمی‌شود و زیر هر فیلد پیام فارسی دیده می‌شود

#### Scenario: Only permitted options
- **WHEN** کاربر فهرست مدل‌ها را باز می‌کند
- **THEN** فقط مدل‌های مجاز او هستند

### Requirement: Pick tools per connection
با انتخاب یک اتصال، کاربر SHALL بتواند ابزارهای لازم همان اتصال را تک‌تک انتخاب کند. (پیشنهادی)

#### Scenario: Choose some tools
- **WHEN** کاربر اتصالی را اضافه و دو ابزار از چهار ابزار را تیک می‌زند
- **THEN** فقط آن دو ابزار برای Agent ثبت می‌شود

### Requirement: Skills and pending approval
کاربر SHALL بتواند مهارت آماده را وارد کند یا مهارت شخصی بسازد. مهارت و اتصال تازه SHALL تا تأیید ادمین «در انتظار تأیید» و غیرفعال باشد و در آزمایش و اجرا استفاده نشود.

#### Scenario: New skill pending
- **WHEN** کاربر مهارت تازه می‌سازد
- **THEN** نشان «در انتظار تأیید ادمین» دارد و در اجرا و آزمایش به‌کار نمی‌رود

#### Scenario: Save with a pending skill
- **WHEN** Agent مهارت در انتظار دارد
- **THEN** ذخیره ممکن است ولی پیام می‌گوید آن مهارت تا تأیید کار نمی‌کند

### Requirement: Test the Agent
کاربر SHALL بتواند Agent را در یک پنل چت کنار فرم آزمایش کند، با همان قواعد دسترسی، سهمیه، تأیید ابزار و ثبت. (پیشنهادی)

#### Scenario: Test
- **WHEN** کاربر در پنل آزمایش پیام می‌فرستد
- **THEN** پاسخ با تنظیمات فعلی فرم می‌آید و ابزار نیازمند تأیید، تأیید می‌خواهد

#### Scenario: Quota exhausted in test
- **WHEN** سهمیه تمام شده
- **THEN** آزمایش ممکن نیست و زمان بازنشانی دیده می‌شود

### Requirement: Validate before saving
پیش از ذخیره، فیلدهای اجباری و سازگاری مدل و ابزار SHALL بررسی شود (مثلاً ابزاری که به قابلیت مدل نیاز دارد) و خطاها به‌روشنی نشان داده شود.

#### Scenario: Incompatible tool and model
- **WHEN** ابزار انتخابی با مدل انتخابی سازگار نیست
- **THEN** ذخیره نمی‌شود و پیام راه حل می‌دهد

### Requirement: Personal use and sharing request
Agent ذخیره‌شده SHALL بلافاصله برای خود کاربر قابل استفاده باشد (استثنا بر قاعده‌ی تأیید ادمین، مشروط به پذیرش کاربر). اشتراک‌گذاری SHALL نیاز به تأیید ادمین داشته باشد: کاربر می‌تواند برای افراد یا گروه‌ها درخواست بدهد و وضعیت «در انتظار»، «تأییدشده» یا «ردشده با دلیل» را ببیند.

#### Scenario: Use right after saving
- **WHEN** کاربر Agent را ذخیره می‌کند
- **THEN** در انتخاب‌گر Agent چت برای خودش هست

#### Scenario: Request sharing
- **WHEN** کاربر برای یک گروه درخواست اشتراک می‌دهد
- **THEN** وضعیت «در انتظار تأیید» دیده می‌شود و Agent هنوز برای دیگران نیست

#### Scenario: Rejected
- **WHEN** درخواست ردشده است
- **THEN** وضعیت «ردشده» با دلیل دیده می‌شود و کاربر می‌تواند دوباره درخواست دهد

### Requirement: Sensitive flag is admin-controlled
پرچم «حساس» و الزام مدل داخلی SHALL برای کاربر فقط‌خواندنی باشد و کاربر نتواند آن را بردارد.

#### Scenario: Sensitive Agent
- **WHEN** Agent پرچم حساس دارد
- **THEN** فرم آن را با توضیح «فقط ادمین تغییر می‌دهد» و بدون امکان تغییر نشان می‌دهد و فقط مدل داخلی قابل انتخاب است

### Requirement: Unsaved changes warning
هنگام ترک فرم با تغییر ذخیره‌نشده، هشدار SHALL بیاید. (پیشنهادی)

#### Scenario: Leaving
- **WHEN** کاربر با تغییر ذخیره‌نشده «بازگشت» را می‌زند
- **THEN** پرسیده می‌شود «ماندن» یا «خروج بدون ذخیره»
