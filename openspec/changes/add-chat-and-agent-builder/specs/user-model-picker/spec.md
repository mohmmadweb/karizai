# Spec Delta

## Purpose

انتخاب مدل کنار کادر پیام.

## ADDED Requirements

### Requirement: Model picker list
انتخاب‌گر مدل SHALL یک منوی کشویی باشد که فقط نام مدل‌های فعال و مجاز برای کاربر را نشان می‌دهد (بدون توضیح؛ مدل داخلی و مدل در دسترس‌نبودن با برچسب کوتاه). گزینه‌ی «انتخاب خودکار» بالای فهرست است.

#### Scenario: Open the picker
- **WHEN** کاربر انتخاب‌گر مدل را باز می‌کند
- **THEN** مدل‌های مجاز با توضیح و قابلیت‌ها و گزینه‌ی «انتخاب خودکار» دیده می‌شوند و مدل غیرفعال یا غیرمجاز نیست

#### Scenario: Search with no result
- **WHEN** جست‌وجو چیزی پیدا نمی‌کند
- **THEN** پیام «مدلی پیدا نشد» دیده می‌شود

#### Scenario: No model available
- **WHEN** هیچ مدل مجازی نیست
- **THEN** پیام «به هیچ مدلی دسترسی ندارید، با ادمین تماس بگیرید» دیده می‌شود و ارسال ممکن نیست

### Requirement: Chosen and used model
مدل انتخاب‌شده SHALL پیش از ارسال کنار کادر پیام دیده شود. اگر «انتخاب خودکار» باشد، کنار هر پاسخ مدل واقعی که جواب داده نوشته شود.

#### Scenario: Automatic choice
- **WHEN** انتخاب خودکار است و پاسخی می‌آید
- **THEN** کنار کادر «خودکار» و کنار پاسخ نام مدل واقعی دیده می‌شود

### Requirement: Incompatible model suggestion
اگر مدل انتخاب‌شده با فایل یا ابزاری که کاربر گذاشته سازگار نباشد (مثلاً تصویر)، ارسال SHALL متوقف شود، دلیل نوشته شود و یک مدل سازگار پیشنهاد شود که با یک کلیک انتخاب می‌شود. (پیشنهادی)

#### Scenario: Image to a text-only model
- **WHEN** کاربر تصویر پیوست کرده و مدل متنی انتخاب شده
- **THEN** پیام می‌گوید این مدل تصویر را نمی‌فهمد و مدل سازگار پیشنهاد می‌شود

### Requirement: Sensitive Agent forces internal model
در Agent حساس، قانون مدل داخلی SHALL بر انتخاب کاربر غالب باشد و کنار کادر نوشته شود که مدل داخلی استفاده می‌شود. اگر مدل داخلی در دسترس نباشد، درخواست SHALL اجرا نشود و دلیل دیده شود.

#### Scenario: Internal model overrides
- **WHEN** کاربر Agent حساس را انتخاب کرده و مدل بیرونی را برگزیده
- **THEN** مدل داخلی به‌جای آن استفاده می‌شود و این نوشته می‌شود

#### Scenario: No internal model
- **WHEN** مدل داخلی در دسترس نیست
- **THEN** ارسال نمی‌شود و پیام می‌گوید چرا
