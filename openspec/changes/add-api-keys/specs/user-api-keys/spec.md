# Spec Delta

## Purpose

ساخت و مدیریت کلید API شخصی برای مدل‌ها، عامل‌ها و پایگاه دانش مجاز کاربر.

## ADDED Requirements

### Requirement: Keys page
صفحه‌ی «API من» SHALL کلیدهای خود کاربر را با نام، نوع و منبع، چند حرف آخر، تاریخ ساخت و انقضا، آخرین استفاده و وضعیت نشان دهد.

#### Scenario: No key yet
- **WHEN** کاربر مجاز است ولی کلیدی ندارد
- **THEN** حالت خالی با دکمه‌ی «کلید تازه» دیده می‌شود

#### Scenario: Not allowed
- **WHEN** هیچ‌کدام از گروه‌های کاربر اجازه‌ی ساخت کلید ندارد
- **THEN** پیام «اجازه‌ی ساخت کلید ندارید» با راهنمای تماس با ادمین دیده می‌شود و دکمه‌ی ساخت نیست

### Requirement: Create a key
کاربر SHALL بتواند با نام، نوع، منبع و انقضا کلید بسازد. نوع‌ها SHALL فقط از اجازه‌ی مجموع گروه‌های او باشند و منبع فقط از مدل‌ها و عامل‌هایی که خودش به آن‌ها دسترسی دارد. سرور SHALL ساخت را برای گروهی که اجازه ندارد رد کند. سقف ماهانه‌ی ادمین SHALL زیر فرم نوشته شود.

#### Scenario: Create
- **WHEN** کاربر نام، نوع، منبع و انقضا را می‌دهد و «ساخت کلید» را می‌زند
- **THEN** کلید به فهرست اضافه می‌شود و متن کامل آن یک بار با دکمه‌ی کپی نشان داده می‌شود

#### Scenario: Missing name or resource
- **WHEN** نام یا منبع خالی است
- **THEN** خطای فارسی دیده می‌شود و کلید ساخته نمی‌شود

#### Scenario: Shown once
- **WHEN** کاربر پنجره‌ی کلید را می‌بندد
- **THEN** متن کلید دیگر نمایش داده نمی‌شود و فقط چند حرف آخرش در فهرست می‌ماند

### Requirement: Revoke
کاربر SHALL بتواند کلید فعال خودش را پس از تأیید ابطال کند و SHALL فقط به کلیدهای خودش دسترسی داشته باشد.

#### Scenario: Revoke
- **WHEN** کاربر «ابطال» را می‌زند و تأیید می‌کند
- **THEN** وضعیت کلید «ابطال‌شده» می‌شود

### Requirement: Usage guide
صفحه SHALL برای هر نوع مجاز نمونه‌ی `curl` با سرآیند Authorization نشان دهد.

#### Scenario: Guide
- **WHEN** کاربر برای مدل و عامل مجاز است
- **THEN** دو نمونه‌ی مدل و عامل دیده می‌شود
