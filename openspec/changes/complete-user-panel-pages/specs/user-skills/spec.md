# Spec Delta

## Purpose

مدیریت اسکیل‌های شخصی کاربر.

## ADDED Requirements

### Requirement: Skills list
صفحه‌ی «اسکیل‌های من» SHALL فهرست اسکیل‌ها را با نام، توضیح کاربرد، وضعیت تأیید و دلیل رد نشان دهد، با جست‌وجو.

#### Scenario: List and search
- **WHEN** کاربر عبارتی می‌نویسد
- **THEN** فقط اسکیل‌های مرتبط می‌مانند

#### Scenario: Rejected skill
- **WHEN** اسکیلی رد شده است
- **THEN** نشان «ردشده» و دلیل دیده می‌شود

### Requirement: Create and import a skill
کاربر SHALL بتواند اسکیل با نام، توضیح کاربرد و دستورالعمل بسازد یا از فایل متنی وارد کند. نام و دستورالعمل اجباری‌اند. اسکیل تازه تا تأیید ادمین «در انتظار» است.

#### Scenario: Create
- **WHEN** کاربر فرم را درست پر می‌کند
- **THEN** اسکیل با وضعیت «در انتظار تأیید» ساخته می‌شود

#### Scenario: Import from file
- **WHEN** کاربر فایل متنی انتخاب می‌کند
- **THEN** نام و دستورالعمل از فایل در فرم پر می‌شود و کاربر می‌تواند پیش از ثبت ویرایش کند

#### Scenario: Wrong file
- **WHEN** فایل نامعتبر یا خالی است
- **THEN** پیام خطای فارسی دیده می‌شود

### Requirement: Edit with re-approval
ویرایش اسکیل تأییدشده SHALL یک نسخه‌ی «در انتظار تأیید» بسازد و نسخه‌ی فعال تا تأیید جایگزین نشود.

#### Scenario: Edit approved skill
- **WHEN** کاربر اسکیل تأییدشده را ویرایش می‌کند
- **THEN** نسخه‌ی فعال همان می‌ماند و نشان «نسخه‌ی جدید در انتظار تأیید» دیده می‌شود

### Requirement: Attach skills to Agents
کاربر SHALL بتواند اسکیل را به Agentهای خودش اضافه یا از آن‌ها جدا کند.

#### Scenario: Attach
- **WHEN** کاربر Agentی را تیک می‌زند و ذخیره می‌کند
- **THEN** اسکیل در آن Agent دیده می‌شود

#### Scenario: Detach
- **WHEN** تیک Agent را برمی‌دارد
- **THEN** اسکیل از آن Agent جدا می‌شود
