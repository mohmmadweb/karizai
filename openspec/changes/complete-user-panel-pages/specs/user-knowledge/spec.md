# Spec Delta

## Purpose

مشاهده و استفاده از دانش سازمان (فقط‌خواندنی).

## ADDED Requirements

### Requirement: Knowledge list
«دانش سازمان» SHALL فقط اسناد و مجموعه‌های مجاز کاربر را با نام منبع و زمان آخرین به‌روزرسانی (اگر موجود بود) نشان دهد، با جست‌وجو. مدیریت و بارگذاری در این صفحه نیست.

#### Scenario: List
- **WHEN** کاربر صفحه را باز می‌کند
- **THEN** اسناد مجاز با منبع و تاریخ شمسی دیده می‌شوند

#### Scenario: No result
- **WHEN** جست‌وجو نتیجه ندارد
- **THEN** پیام «سندی پیدا نشد» دیده می‌شود

#### Scenario: Missing date
- **WHEN** زمان به‌روزرسانی سندی نامعلوم است
- **THEN** تاریخ نشان داده نمی‌شود

### Requirement: Start a conversation about a document
کاربر SHALL بتواند درباره‌ی سند انتخاب‌شده گفتگو شروع کند.

#### Scenario: Start
- **WHEN** کاربر «گفتگو درباره‌ی این سند» را می‌زند
- **THEN** گفتگوی تازه با پیام آماده درباره‌ی همان سند در کادر پیام باز می‌شود
